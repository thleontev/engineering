# CAD

Публичная механическая модель Fire Lamp публикуется только в нейтральном обменном формате STEP.

Нативные исходники КОМПАС-3D, Rhino и Grasshopper в этот репозиторий не включаются.

## Ревизия

Текущая рабочая механика относится к семейству R1.x. Для публичной публикации используется сборочная модель актуальной проверяемой ревизии.

## STEP

Файл полной сборки должен располагаться здесь:

```text
fire-lamp/cad/fire-lamp-assembly.step
```

Исходный STEP хранится во внутреннем репозитории через Git LFS. В текущей публикации он ещё не перенесён, чтобы не публиковать LFS pointer вместо реальной CAD-модели.
