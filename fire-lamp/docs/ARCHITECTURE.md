# Архитектура Fire Lamp

## Назначение

Fire Lamp — адресный светильник на ESP32-S3, в котором один контроллер управляет LED-матрицей и обрабатывает локальные датчики. Актуальная аппаратная версия — LumaCore-S3-PWR-R2 (публичная PCB R2.1).

## Функциональная схема

```text
5 V DC
  │
  ├──────────────→ LED matrix WS2812B 16×16 (256)
  │
  └→ LumaCore-S3-PWR-R2
          │
          ├→ ESP32-S3-WROOM-1-N16R8
          ├→ GPIO17 → LED DATA
          ├→ GPIO21 → LED enable
          ├→ GPIO4  ← PIR
          └→ I²C (GPIO47 SDA, GPIO48 SCL)
                   │
                   └→ VEML7700 (0x10)
                        │
                        ▼
                   WLED + AutoNightLight
```

## Автоматический ночной режим

AutoNightLight использует PIR для обнаружения движения и VEML7700 для определения освещённости. Когда лампа выключена, измерение актуально и темно, движение может включить WLED preset. После окончания движения запускается задержка выключения; ручное управление имеет приоритет. После ручного выключения действует пауза и ожидание неактивного PIR перед новым срабатыванием.

Для R2 датчик VEML7700 выбирается на этапе сборки прошивки, без автоматического переключения на BH1750. Измерение с ошибкой, после смены диапазона или устаревшее не разрешает автоматическое включение. Автоматическая регулировка усиления/времени интеграции инициализируется с 1/8× и 100 мс. Номинальный порог в заводском профиле R2 — 0,1 лк; настройка не является результатом оптической калибровки готового изделия.

## Разделение исходников

- [PCB](../pcb/) и [CAD](../cad/) — публичные инженерные материалы;
- [Firmware](../firmware/) — опубликованный исходный код пользовательского модуля AutoNightLight с VEML7700;
- WLED — сторонний проект, полная базовая прошивка сюда не включена.

Здесь опубликован модуль, а не готовый бинарный образ WLED. Прошивка с VEML7700 несовместима с устройством, где физически установлен только BH1750. Сборка не заменяет электрическую проверку конкретного экземпляра.
