# Архитектура Fire Lamp

## Назначение

Fire Lamp — автономный адресный светильник, в котором один контроллер управляет LED-матрицей и обрабатывает локальные датчики.

## Функциональная схема

```text
5 V DC
  │
  ├──────────────→ LED matrix WS2812B 16×16
  │
  └→ LumaCore-S3-PWR
          │
          ├→ ESP32-S3
          ├→ LED DATA
          ├→ PIR
          └→ BH1750
                │
                ▼
              WLED
                │
                └→ AutoNightLight usermod
```

## Контроллер

Основой электроники является LumaCore-S3-PWR — плата управления на ESP32-S3, рассчитанная на работу с адресными светодиодами и внешними датчиками.

## LED-матрица

Используется матрица WS2812B 16×16, всего 256 пикселей. Управление выполняется одним цифровым каналом DATA.

## Автоматический режим

Пользовательский модуль WLED использует два сигнала:

- PIR — наличие движения;
- BH1750 — текущая освещённость.

При низкой освещённости и обнаружении движения модуль может включить заданный WLED preset. После прекращения движения запускается задержка выключения. Ручное управление имеет приоритет над автоматикой.

## Разделение проекта

Механика, PCB и firmware публикуются раздельными каталогами, но относятся к одному изделию и должны рассматриваться совместно.
