# AutoNightLight — WLED usermod

Компактный модуль для **WLED 0.16.x**: PIR включает preset только в темноте, измеренной **VEML7700**. Прошивка WLED в репозитории не дублируется.

## Файлы

- `autonightlight.cpp` — автомат PIR, применение preset, плавные переходы, сохранение предыдущего состояния в RAM и пользовательские настройки.
- `autonightlight.h` — интерфейс класса.
- `veml7700.h` — I²C-драйвер без блокирующих ожиданий, проверка датчика и автоматическая чувствительность.
- `library.json` — регистрация библиотеки PlatformIO.

## Установка

Скопируйте **всю папку** `usermod/` в каталог `WLED/usermods/AutoNightLight/`. В `platformio_override.ini` добавьте отдельную среду, выбрав базовое окружение под вашу плату:

```ini
[env:firelamp_s3_autonightlight]
extends = env:esp32s3dev_16MB_opi
custom_usermods =
  ${env:esp32s3dev_16MB_opi.custom_usermods}
  AutoNightLight
build_flags =
  ${env:esp32s3dev_16MB_opi.build_flags}
  -D AUTONIGHTLIGHT_PIR_PIN=4
  -D AUTONIGHTLIGHT_SDA_PIN=47
  -D AUTONIGHTLIGHT_SCL_PIN=48
```

Соберите WLED: `pio run -e firelamp_s3_autonightlight`. Сборка должна использовать WLED 0.16.x с `REGISTER_USERMOD()` и `custom_usermods`. Для другой платы укажите её реальные GPIO и корректное базовое окружение.

Подключение: VEML7700 I²C `0x10`, **3,3 В**, SDA GPIO47, SCL GPIO48; PIR OUT GPIO4 (HIGH = motion). Проверьте уровни и подтяжки конкретного датчика; напряжение питания breakout-платы может отличаться от напряжения самой микросхемы.

## Логика

- После запуска модуль ждёт хотя бы одного измеренного неактивного уровня PIR, чтобы избежать включения при загрузке.
- По новому событию движения в темноте запускает **существующий WLED preset** `OnPreset`. В preset должны быть сегменты с эффектом `fx`; команды, playlist и отсутствие preset отклоняются.
- `OffDelaySec` отсчитывается после окончания движения, повторное движение отменяет ожидание выключения.
- Если свет уже включён вручную, модуль не меняет его. Ручное управление во время автоматического режима прекращает автоматическое владение сценой.
- После ручного OFF срабатывает пауза `ManualOffPauseSec`; для следующего запуска PIR должен стать неактивным и дать новое событие.
- Недействительное или устаревшее измерение VEML7700 блокирует запуск.

Настройки WLED Usermods: `Enabled` (true), `LuxThreshold` (5 лк), `OffDelaySec` (120 с), `ManualOffPauseSec` (600 с), `TransitionSec` (2 с), `OnPreset` (2). `LuxThreshold` задаётся в **физических люксах**, не в условных единицах. Для чувствительного ночного режима можно начать с 0,1 лк, но значение следует подобрать по измерениям в корпусе.

VEML7700 запускается с gain 1/8 и интеграцией 100 мс, затем при слабом освещении автоматически поднимается до 2×/800 мс. После смены диапазона, ошибок I²C или насыщения прежний lux не используется. Интервал чтения — 2 с, свежесть — до 4,5 с; номинальные коэффициенты не заменяют калибровку.

## Границы и проверка

Это **публикуемая автономная реализация usermod**, не бинарная прошивка изделия. Отдельные заводские функции и внутренние сервисы здесь не используются.

Перед установкой на физическое устройство проверьте: сборку под точную версию WLED и целевой ESP32, наличие preset, чтение VEML7700, работу PIR, плавность переходов, приоритет ручного управления, 20 повторных циклов и отсутствие ложного включения при ошибке I²C. Проверка исходников без аппаратного стенда не подтверждает прохождение этих тестов.
