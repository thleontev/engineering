# AutoNightLight — WLED usermod

Исходный код пользовательского модуля, автоматически включающего ночной preset WLED по PIR, когда освещённость ниже порога.

## Состав

- `usermod_lumacore_pir_bh1750.cpp` / `.h` — автомат ночного режима, PIR, manual override и восстановление предыдущего состояния WLED.
- `lumacore_ambient_light.h` — интерфейс датчиков, драйвер VEML7700 и поддержка BH1750.
- `lumacore_veml7700_math.h` — номинальный пересчёт данных VEML7700 и неблокирующая смена диапазонов.
- `lumacore_night_scene.cpp` / `.h` — подготовка сцены при выключенной LED-матрице, проверка preset.
- `lumacore_light_scale.h` — валидация порога в физических люксах и форматирование.
- `library.json` — метаданные библиотеки для PlatformIO.

Имена `usermod_lumacore_pir_bh1750.*` и C++-класса оставлены для совместимости с ранними интеграциями. **По умолчанию выбран VEML7700**.

## Подключение к WLED

Перенесите всю папку `usermod/` в `wled/usermods/usermod_lumacore_pir_bh1750/` вместе с зависимостями из неё. В `platformio_override.ini` нужной среды добавьте пользовательский модуль и параметры GPIO:

```ini
custom_usermods =
  ${env:esp32s3dev_16MB_opi.custom_usermods}
  usermod_lumacore_pir_bh1750

build_flags =
  ${env:esp32s3dev_16MB_opi.build_flags}
  -D USERMOD_LUMACORE_PIR_BH1750
  -D LUMACORE_PIR_PIN=4
  -D LUMACORE_LIGHT_SDA_PIN=47
  -D LUMACORE_LIGHT_SCL_PIN=48
  -D LUMACORE_PIR_ACTIVE_HIGH=1
```

Для **намеренного** использования старого BH1750 добавьте `-D LUMACORE_AMBIENT_SENSOR_BH1750`, указав фактические SDA/SCL и адрес (по умолчанию 0x23). Автоматического переключения между датчиками нет. Выбирайте среду WLED, соответствующую реальному ESP32, flash и PSRAM; приведённый пример сам по себе не настраивает полный образ для Fire Lamp.

Модуль использует API WLED для настроек, presets и управления сегментами. При переносе в другую версию WLED возможна несовместимость API; необходима сборка и проверка на оборудовании.

## Алгоритм

1. PIR активирует `OnPreset` только при действительном, свежем измерении освещённости ниже `LuxThreshold`.
2. При старте устройство должно сначала зарегистрировать **неактивный PIR**: удерживаемый HIGH не включает свет сразу после загрузки.
3. Когда свет уже включён вручную, AutoNightLight не меняет текущую сцену.
4. По окончании движения действует `OffDelaySec`; затем возвращается выключенное предыдущее состояние.
5. Ручной OFF блокирует повторное включение минимум на `ManualOffPauseSec`, а по окончании паузы требуется отпускание PIR и новое движение.

Настройки Usermods: `Enabled` (true), `LuxThreshold` (5 лк по умолчанию, допускается от 0,1), `OffDelaySec` (120 с), `ManualOffPauseSec` (600 с), `TransitionSec` (2 с), `OnPreset` (2). Параметры конкретной лампы задаются отдельно.

VEML7700 по умолчанию запускается в режиме gain 1/8 и 100 мс, затем выбирает чувствительность до 2×/800 мс. Ошибки I²C, перенастройка, насыщение и устаревшие показания сбрасывают valid-состояние; это блокирует автоматическое включение. Номинальный режим 2×/800 мс соответствует 0,0042 лк/отсчёт, но для готового корпуса нужна калибровка.

## Ограничения

Опубликована пользовательская часть, а **не полный образ прошивки**. В этой редакции не включены отдельные интеграции OTA, factory/service, журналирования и внешнего управления. Их отсутствие не препятствует базовому автоматическому ночному сценарию, но означает, что этот набор нельзя считать побайтовой копией прошивки конкретного устройства.

Программная проверка не заменяет тесты реального датчика и платы. Не прошивайте сборку с выбранным VEML7700 на устройство, где фактически установлен только BH1750.
