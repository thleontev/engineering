# Историческая реализация PIR + BH1750

Эти файлы перенесены из прежнего публичного `fire-lamp/firmware/usermod/` **без изменений** исключительно для сохранения истории проекта.

- `usermod_lumacore_pir_bh1750.cpp`
- `usermod_lumacore_pir_bh1750.h`
- `library.json`

Это **устаревшая** реализация под BH1750 (I²C 0x23), не совместимая с актуальным аппаратным датчиком VEML7700 на Fire Lamp S3-PWR-R2. Архив не соответствует текущим требованиям AutoNightLight, ручной паузе, обработке ошибок измерений и другим механизмам основного репозитория.

**Не использовать для текущей сборки или прошивки.** Актуальный код и порядок работы: [LumaCore-Labs/lumacore-firmware](https://github.com/LumaCore-Labs/lumacore-firmware). См. [публичное описание firmware](../../README.md).
