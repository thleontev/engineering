# Fire Lamp — AutoNightLight

В этом разделе опубликован **только пользовательский модуль WLED** для автоматического ночного режима Fire Lamp: исходники и необходимые для него вспомогательные файлы. Полная прошивка WLED, профили устройств, настройки сети и образы для прошивки сюда не входят.

- [Исходный код AutoNightLight](usermod/)
- Платформа: ESP32-S3, WLED 16.0.1.
- Датчик освещённости: **VEML7700** по I²C (0x10), GPIO47 SDA / GPIO48 SCL для S3-PWR-R2.
- PIR: GPIO4, уровень HIGH при движении.
- Исторический BH1750 (0x23) может быть явно выбран флагом сборки `LUMACORE_AMBIENT_SENSOR_BH1750`.

Заводские конфигурации, наборы presets и параметры конкретных устройств не публикуются. Исходный код сам по себе не является готовой прошивкой для платы. Перед сборкой, подключением или прошивкой необходимо проверить фактически установленный датчик и соответствие аппаратным интерфейсам.
