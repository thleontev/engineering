# Fire Lamp — firmware

В открытом каталоге опубликован **только пользовательский модуль AutoNightLight для WLED**, без базовой прошивки, конфигураций конкретного устройства, образов и производственных данных.

- [AutoNightLight (исходники и инструкция)](usermod/) — PIR + VEML7700.
- Платформа: ESP32-S3, WLED 0.16.x.
- I²C: VEML7700 `0x10`, GPIO47 SDA и GPIO48 SCL; PIR GPIO4.
- Пользовательский сценарий: включение WLED preset в темноте, задержка выключения, плавные переходы, приоритет ручного управления.

Собирается в исходном дереве WLED как `custom_usermods = AutoNightLight`. Это не готовый бинарный образ для прошивки. Соответствие GPIO, питания и сенсора необходимо проверить для своей платы.
