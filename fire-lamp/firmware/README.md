# Fire Lamp — firmware

Этот каталог — **публичное описание** прошивки Fire Lamp, а не самостоятельный комплект для сборки. Основной источник кода, профилей, CI и инструкций: [LumaCore-Labs/lumacore-firmware](https://github.com/LumaCore-Labs/lumacore-firmware) (приватный репозиторий, требуется доступ).

Актуальная версия для **LumaCore-S3-PWR-R2 / ESP32-S3-WROOM-1-N16R8** построена на WLED `v16.0.1` и пользовательском модуле `AutoNightLight`. Разработка Fire Lamp сейчас приостановлена на стадии рабочего прототипа; наличие профиля не означает квалификацию серийного изделия.

## Датчики и интерфейсы R2

| Функция | Актуальная конфигурация |
|---|---|
| Датчик освещённости | **VEML7700**, I²C-адрес `0x10` |
| I²C | SDA **GPIO47**, SCL **GPIO48** |
| PIR | **GPIO4**, активный HIGH |
| LED-матрица | WS2812B 16×16 (256), DATA **GPIO17** |
| Управление LED | GPIO21 |
| Ключевой параметр WLED | `AutoNightLight.LuxThreshold = 0.1` лк в заводском профиле R2 |
| Лимит тока WLED | **6500 мА** (программное ограничение яркости, не защита от перегрузки) |

Датчик выбирается при компиляции: `LUMACORE_AMBIENT_SENSOR_VEML7700` для S3-PWR-R2. Автоматического отката на BH1750 **нет**. Установленная прошивка должна соответствовать фактически распаянному датчику. Сборка под VEML7700 не предназначена для платы с BH1750 без замены датчика.

VEML7700 имеет автоматический выбор усиления/времени интеграции без блокирующих ожиданий. При недействительном или устаревшем измерении AutoNightLight не включает свет по PIR. Номинальная чувствительность и порог 0,1 лк требуют проверки на реальном корпусе.

## Сценарий AutoNightLight

1. При валидной освещённости ниже `LuxThreshold` PIR может активировать `OnPreset`.
2. Если свет уже включён вручную, автомат не заменяет выбранный режим.
3. После окончания движения действует `OffDelaySec`; для автоматического выключения используется `TransitionSec`.
4. Ручное выключение блокирует повторный запуск минимум на `ManualOffPauseSec` (по умолчанию 600 с), а затем автоматика ждёт неактивного PIR и следующего движения.
5. Состояние WLED до автоматического включения сохраняется в RAM и восстанавливается после автоматического выключения.

Имена `usermod_lumacore_pir_bh1750.*` и C++-класса в основном репозитории сохранены ради совместимости, хотя R2 использует VEML7700. Наличие `bh1750` в имени файла **не означает**, что текущий S3-PWR-R2 работает с этим датчиком.

## Публичные материалы этого каталога

- [config/cfg.example.json](config/cfg.example.json) — **обезличенный пример**, параметры аппаратной части и AutoNightLight приведены к R2. Это не экспорт рабочего экземпляра и не источник заводского профиля.
- [config/presets.example.json](config/presets.example.json) — исторические демонстрационные эффекты; **не текущий набор заводских presets**.
- [usermod/README.md](usermod/README.md) — указатель на поддерживаемый модуль.
- [legacy/bh1750/](legacy/bh1750/) — неизменённые исходники прежней реализации BH1750, только для истории.

**Важно:** не собирать и не прошивать R2 из архива. Действующие профили, полная сборка WLED, проверка совместимости железа и прошивка выполняются по инструкциям основного репозитория. Wi-Fi/MQTT/OTA-учётные данные не включаются в публичные примеры.
