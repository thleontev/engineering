# Firmware

Fire Lamp использует WLED с пользовательским модулем LumaCore AutoNightLight.

Полный исходный код upstream WLED в этот репозиторий не дублируется. Здесь публикуются только изменения и настройки, относящиеся к Fire Lamp.

## Возможности AutoNightLight

Модуль объединяет:

- PIR-датчик движения;
- BH1750;
- автоматический запуск выбранного preset;
- задержку выключения;
- плавное включение и выключение;
- сохранение предыдущего состояния WLED в RAM;
- приоритет ручного управления.

## Логика

1. Проверяется уровень освещённости.
2. Если достаточно темно, разрешается реакция на PIR.
3. При обнаружении движения включается заданный preset.
4. После окончания движения запускается таймер.
5. По завершении таймера светильник выключается.
6. Если пользователь вручную выключил свет, автоматика не включает его повторно до завершения текущего события движения.

## Содержимое

- `usermod/` — исходный код пользовательского модуля;
- `config/` — пример конфигурации без паролей и данных конкретного устройства.

Конфигурационные файлы являются шаблонами. Учётные данные Wi-Fi, OTA, MQTT и другие секреты в репозиторий не включаются.
