# Engineering

Репозиторий инженерных проектов и разработок.

Здесь собраны законченные и демонстрационные проекты по электронике, встроенному ПО, CAD, прототипированию и подготовке изделий к производству.

## Проекты

### Fire Lamp

Настольный ночник с эффектом пламени и светомузыкой на базе ESP32-S3 и WLED.

В проекте объединены:

- механическая конструкция и CAD;
- проектирование схемы и печатной платы;
- силовая часть для адресной LED-матрицы;
- встроенное ПО и пользовательский модуль WLED;
- датчик движения и датчик освещённости;
- сборка, прототипирование и испытания.

→ [Fire Lamp](fire-lamp/)

### Подсолнух / Sunflower

Настольный ночник в форме подсолнуха со сменной лампой GX53.

В проекте объединены:

- предметный дизайн и механическая компоновка;
- справочная сборка STEP;
- детали для FDM-печати и проект Bambu Studio;
- перечень компонентов и крепежа;
- вариант лампы YNDX-00556 с управлением через Алису;
- визуализация внешнего вида и внутреннего устройства.

→ [Подсолнух](sunflower/)

## Принцип публикации

В репозитории размещаются только материалы, которые подходят для публичного просмотра и воспроизведения проекта. Рабочие внутренние документы, данные поставщиков, учётные данные и незавершённые эксперименты не публикуются.
