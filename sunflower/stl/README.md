# Файлы для 3D-печати

[sunflower.3mf](sunflower.3mf) — сохранённый проект печати для Bambu Studio с семью столами. Отдельные STL расположены в этой же папке.

## Детали

| Деталь | Файл | Количество на сборку |
| --- | --- | ---: |
| Корпус | [body.stl](body.stl) | 1 |
| Подставка-верх | [base-upper.stl](base-upper.stl) | 1 |
| Подставка-низ | [base-lower.stl](base-lower.stl) | 1 |
| Плафон-верх | [shade-upper.stl](shade-upper.stl) | 1 |
| Плафон-низ | [shade-lower.stl](shade-lower.stl) | 1 |
| Рассеиватель | [diffuser.stl](diffuser.stl) | 1 |
| Лепесток | [petal.stl](petal.stl) | 14 по CAD; в 3MF размещено 15 |

Единицы координат STL — миллиметры; масштаб импорта 100%. Ориентация отдельных STL соответствует исходному экспорту и может отличаться от ориентации для печати. В 3MF сохранены положения деталей на столах.

Лепесток извлечён из геометрии 3MF без масштабирования: в исходном наборе отдельных STL его не было. У корпуса и верхней части подставки при подготовке STL объединены совпадающие в допуске вершины; число треугольников сохранено. Исходная раскладка и настройки 3MF сохранены.

## Сохранённый профиль 3MF

| Параметр | Значение |
| --- | --- |
| Принтер | Bambu Lab A1 |
| Сопло | 0,4 мм |
| Материал | PETG, пользовательский профиль LIDER-3D PETG PETG+ |
| Цвета | Зелёный, белый, жёлтый |
| Высота слоя | 0,20 мм |
| Первый слой | 0,20 мм |
| Стенки | 2 периметра |
| Заполнение | 15% |
| Поддержки | Включены, автоматические древовидные |
| Пластина | Textured PEI Plate |

Это параметры сохранённого проекта, а не универсальный профиль для любого PETG и принтера. Перед печатью проверьте выбранные материалы, температуры, поддержки, ориентацию и предварительный просмотр слоёв. Файлы G-code не публикуются.

## Раскладка по столам

1. Подставка-верх.
2. Подставка-низ.
3. Корпус.
4. Плафон-низ.
5. Лепестки, 15 экземпляров.
6. Плафон-верх.
7. Рассеиватель.

Шесть исходных STL сверены с соответствующей геометрией внутри 3MF. Сетки проверяются как замкнутые после объединения совпадающих вершин. Это не заменяет проверку посадок и пробную печать.

Покупные детали и крепёж приведены в [BOM](../docs/BOM.md). STEP имеет [отличия от комплекта печати](../cad/README.md) и служит справочной компоновкой.
