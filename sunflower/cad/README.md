# Механическая модель

[sunflower-assembly.step](sunflower-assembly.step) — справочная компоновка ночника из рабочей папки CAD v2.4.

## Назначение

Модель позволяет изучить взаимное расположение основания, корпуса, плафона, лепестков, патрона, лампы и крепежа. В CAD показан вариант лампы GX53 Ecola. Альтернатива YNDX-00556 указана в [BOM](../docs/BOM.md).

Файл для публикации повторно экспортирован из твёрдых тел исходного STEP: сохранены все 47 твёрдых тел в их положениях, отдельно стоящие вспомогательные поверхности исключены. При повторном импорте проверены количество тел и корректность их геометрии.

## Соответствие файлам печати

STEP и STL/3MF являются разными сохранёнными представлениями проекта. Полное соответствие геометрии между ними не подтверждено; при проверке обнаружены различия верхней части подставки и верхней части плафона. В частности, узел верхней части подставки в исходном STEP содержит два твёрдых тела, а для печати используется одна сетка отдельной детали.

Для изготовления используйте [STL и 3MF](../3d-printing/), а STEP — для просмотра компоновки. Не создавайте из этого STEP замену всем печатным деталям без дополнительной сверки.

В STEP размещено 14 лепестков. В 3MF сохранена раскладка с 15 экземплярами; её количество можно изменить перед печатью.

## Проверка

При подготовке публикации выполнены импорт STEP, проверка твёрдых тел и визуальный просмотр тесселированной сборки. Это проверка цифровой модели, а не подтверждение посадок, собираемости и результатов изготовления.

Нативные файлы КОМПАС-3D и история разработки остаются вне публичного комплекта.
